# Calculadora de Recarga — Viação Praiana

Sistema interno para calcular quantas passagens cabem no valor recarregado no Passe Fácil.

**Acesso web:** https://jbr121.github.io/contador-de-passagem/

Exemplo: Itajaí → Camboriú com R$ 50,00 = 5 passagens (usa R$ 42,25, sobra R$ 7,75).

Tarifas conforme o Informativo Oficial vigente a partir de 19/07/2026 (SIE/SC).
